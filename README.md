# 매일 타로 (daily-tarot-pwa)

매일 타로로 보는 하루 — 아침에 카드 3장을 뽑아 오늘을 명상하고, 저녁에 하루를 기록하는 개인 타로 저널 PWA입니다.

## 스프레드: 쓰리 카드 일일 명상법 (100일)

"분리 배열법(78장 전체) – 응용 예"를 기반으로 한 3장 스프레드를 사용합니다.

1. **오늘의 원형 (메이저 22장)** — 오늘 하루 나와 함께하는 원형, 상징(분위기·주제·날씨)은?
2. **오늘의 인물상 (인물 16장)** — 이 원형은 오늘 나에게 어떤 인물로 살아가는가?
3. **현실적 행동과 결과 (마이너 40장)** — 이 원형의 현실적 행동, 구체적 결과, 오늘 일어나는 일은?

## 고정 에너지 컨텍스트

| 에너지 분류 | 설정 카드 | 해석 가중치 |
| --- | --- | --- |
| 영혼 & 성격 카드 | 7번 전차 (The Chariot) | 30% |
| 올해의 카드 | 11번 정의 (Justice) | 25% |
| 이달 / 이번 주 | 펜타클 10 / 별 카드 | 20% |
| 오늘의 카드 (3장) | 사용자 직접 입력 | 25% |

## 주요 기능

- 3개 카드 슬롯 + 검색 가능한 카드 선택 UI (모바일 한 손 조작 최적화)
- 아침 명상: 3장 카드 + 고정 에너지를 결합한 오늘의 메시지 생성
- 저녁 성찰: 실제 하루 기록 → 아침 해석과 대조한 피드백
- 월간 분석 리포트: 주차별 명상 횟수, 메이저 아르카나 출현 빈도, 평균 만족도
- PWA: 홈 화면에 추가하여 네이티브 앱처럼 사용
- 모든 데이터는 브라우저 로컬 저장소에만 저장 (서버 없음)
- 설정에서 Claude API 키를 등록하면 AI 해석을 사용하고, 없으면 내장 템플릿 엔진으로 동작

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드
npm run preview  # 빌드 결과 미리보기
npm run lint     # 린트
```
